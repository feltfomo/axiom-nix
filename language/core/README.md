# Admitted core

The core uses generation `axiom-core-syntax-2`, absolute De Bruijn levels, explicit level expressions, and bounded first-order admission.

Its primitive families are universes, dependent functions, dependent pairs, binary sums, Unit, Empty, and intensional identity with general J. J motives bind source, target, and evidence in that order. The refl branch binds only its witness.

The equation inventories tie structural, level, and family laws to their owners and permanent gates. They contain no semantic dispatch. The closed traversal follows schema child order and binder increments without giving the schema control over evaluation, checking, conversion, or readback.

Definitional conversion admits function eta, surjective-pair eta, and typed Unit uniqueness. Binary sums, Empty, and identity have no eta rule. Universes are non-cumulative.
