# Private kernel

The private kernel validates contexts, forms types, infers and checks terms, compares types and terms by normalization by evaluation, and reads semantic values back to canonical core syntax.

Contexts align absolute syntax levels with evaluator environments and retain a semantic type for every level. Kernel evidence uses generation `axiom-kernel-1` and is not exported by the public language module.

Conversion has two independent decisions above typed-neutral replay. The optimized decision consumes Logismos relations through conversion-owned closed handler records whose keys exactly match the evaluator's conversion inventories, and it never calls canonical readback or the oracle. The reference decision compares bounded canonical readbacks after core admission. Both decisions use the same kernel-owned typed-transition component, so their agreement cannot independently validate transition advancement. Independently constructed successors, complete readback envelopes, and focused transition mutations provide that evidence. Function readback is eta-long, dependent-pair readback is surjective, and every well-typed Unit value reads back as `unit`. Binary sums, Empty, and identity have no eta rule.

A top-level judgment owns one state containing checking, conversion, semantic-comparison, readback, context, output, and depth accounts. Nested checking, conversion, forcing, and quotation thread that state monotonically. Each operation charges before inspecting the syntax or semantic payload it would consume, and exhaustion returns a structured refusal with the exact account, limit, and consumed amount.

Neutral spines carry an exact count and are traversed oldest-first under the comparison or readback limit. Application, both projections, sum elimination, Unit elimination, Empty elimination, and identity elimination are replayed and compared at their reconstructed dependent types. Semantic cells, closures, environments, neutral heads, and eliminator payloads are validated before use.

Only judgment-specific private constructors create trusted successes. Validators require exact fields, the private kernel generation, current evaluator semantics, canonical syntax where applicable, and an exact resource summary.
