# Private kernel

The private kernel validates contexts, forms types, infers and checks terms, compares types and terms by normalization by evaluation, and reads semantic values back to canonical core syntax.

Contexts align absolute syntax levels with evaluator environments and retain a semantic type for every level. Kernel evidence uses generation `axiom-kernel-2` and is not exported by the public language module.

Conversion has two independent decisions above typed-neutral replay. The optimized decision consumes Logismos relations through conversion-owned closed handler records whose keys exactly match the evaluator's conversion inventories, and it never calls canonical readback or the oracle. The reference decision compares bounded canonical readbacks after core admission. Both decisions use the same kernel-owned typed-transition component, so their agreement cannot independently validate transition advancement. Independently constructed successors, complete readback envelopes, and focused transition mutations provide that evidence. Function readback is eta-long, dependent-pair readback is surjective, and every well-typed Unit value reads back as `unit`. Binary sums, Empty, and identity have no eta rule.

A top-level judgment owns one state with eleven exact resource fields. Application counts semantic application and `applyMany` extension, checking counts rule entry, comparison counts relation decisions, context counts trusted insertion, conversion counts premise entry, demand counts semantic-cell demand, output counts canonical constructors, projection counts semantic projection, readback counts type-directed quotation, transition counts protected replay payloads, and depth records the maximum charged judgment depth. Named complete vectors keep those owners independent of their callers.

Nested operations thread that state monotonically. Each charge precedes the syntax or semantic payload it protects, and exhaustion returns the exact owner, limit, and pre-operation usage. Independent limits intentionally replace the former aggregate readback ceiling; mixed work is constrained by each operation it actually performs rather than a generic total-work account.

Neutral spines carry an exact count and are traversed oldest-first after their complete transition cost is reserved. Application, both projections, sum elimination, Unit elimination, Empty elimination, and identity elimination are replayed and compared at their reconstructed dependent types. Semantic cells, closures, environments, neutral heads, and eliminator payloads are validated before use.

Only judgment-specific private constructors create trusted successes. Validators require exact fields, the private kernel generation, current evaluator semantics, canonical syntax where applicable, and an exact resource summary.
